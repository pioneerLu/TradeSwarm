## 一、HOLD 问题修复（2026-02-24 ~ 02-25）

### 问题

系统持续输出 HOLD，不执行交易。根因是决策链中多个环节存在 HOLD 倾向：

1. **Trader LLM 偏保守**：prompt 未约束「不得轻易 HOLD」，信息不充分时 LLM 倾向 HOLD
2. **Strategy Selector 短路**：Trader=HOLD 时直接返回 `strategy_selection: None`，不调用 LLM
3. **default_timing 占位符**：`default_timing_strategy()` 固定返回 `Signal.HOLD`
4. **Risk Manager 输入错误**：使用的是 Research 的 investment_plan 而非 Trader 的输出
5. **Trader 输出解析失败**：JSON 解析失败时默认为 HOLD
6. **Market Open 双重校验**：策略信号 BUY/SELL 时仍检查 Trader action，若为 HOLD 则拦截

### 已实施方案

| 方案 | 文件 | 改动 |
|------|------|------|
| A: Trader Prompt 约束 | `trader/prompt.j2` | 增加「不得轻易选择 HOLD」，有倾向时应给 BUY/SELL |
| C: Strategy Selector 兜底 | `strategy_selector/agent.py` | Trader=HOLD 时返回 default_timing 而非 None |
| D: default_timing 真实逻辑 | `strategy_lib.py` | 实现宽松 MA20 规则：未持仓且 price>MA20 则 BUY |
| E: Risk 使用 Trader 输出 | `risk_manager/agent.py` + `prompt.j2` | 优先使用 `trader_investment_plan`，fallback 到 Research |
| F: Market Open 兜底 | `market_open/node.py` | default_timing 策略时允许信号覆盖 Trader HOLD |
| 诊断日志 | `debug_backtest_log.py` | 每日记录 trader_action / strategy / risk / market_open 决策 |

### 未实施（可选）

- **方案 B**：Trader Structured Output（Pydantic/JSON Schema）—— 若仍有解析问题可实施
- **方案 G**：放宽技术策略阈值 —— 需回测评估假信号风险

### build_analyst_dataset.py 关键参数

| 参数 | 说明 |
|------|------|
| `--dates DATE1,DATE2` | 指定精确日期（解决 --end 日期错位问题） |

### API 限流防护

- **Alpha Vantage 限制**：免费版 5 次/分钟，500 次/天
- **已实现**：news/fundamentals/sentiment 间 `sleep(13)` 秒
- **失败不写入**：报告含「未能获取」「API 失效」「密钥耗尽」等表述时自动跳过 DB 写入
- **增量补全**：`--only-missing` 按 (date, analyst_type) 检测，跳过已有有效报告

## 五、回测系统设计要点

### 日级流程

```
Pre-Open Graph（LangGraph 图内决策）
  Summary → Research（多空辩论）→ Trader → Strategy Selector → Risk（风险辩论）
      ↓
Market Open（图外执行交易）
  读取 risk_summary + strategy_selection → execute_strategy → buy/sell
      ↓
Post Close（图外更新收益）
  更新收盘价 → 计算收益率 → 保存 daily_trading_summaries
```

### 交易执行条件（AND 门）

1. Risk Manager `final_decision` ≠ HOLD
2. Strategy Selector 返回非空 `strategy_selection`
3. 技术策略 `execute_strategy()` 返回 BUY 或 SELL 信号
4. 当策略为非 default_timing 时，Trader action 不为 HOLD

### 数据库表

| 表 | 说明 |
|------|------|
| `analyst_reports` | 4 类分析师原始报告（market, news, sentiment, fundamentals） |
| `analyst_summaries` | 7 日滚动窗口摘要（唯一约束: analyst_type + symbol + trade_date） |
| `daily_trading_summaries` | 每日交易摘要（market_regime, strategy, return 等） |
| `cycle_reflections` | 周期反思记录 |
